Plugin sales, licensing, updates, reviews, and related site features for webd.uk.

== Description ==

Combines the webd.uk plugin repository, WooCommerce sales and licensing integration, plugin reviews, and site features in one plugin. WooCommerce is required.

== Installation ==

1. Install and activate WooCommerce.
2. Install and activate webd.uk Repository.
